# Brainstorming（头脑风暴）

## 流程
1. 生成 3-5 个**差异化**方案（不要都差不多的变体）
2. 每个方案列出：核心思路、优点、代价/风险、适用场景
3. 对照需求权衡：按"满足度 × 成本 × 风险"排序
4. 收敛到推荐方案，说明理由；保留备选

## 原则
- 先发散后收敛：不要一开始就锁定唯一想法
- 方案要具体可执行，不空泛
- 权衡有明确标准（性能/复杂度/可维护性/时间），不凭感觉
