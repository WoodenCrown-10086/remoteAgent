# Executing Plans（执行计划）

## 执行纪律
1. 按计划顺序执行，不跳步、不擅自扩大范围
2. 每完成一步：立即验证（编译/测试/运行），记录结果
3. 验证失败 → 停下定位修复（见 systematic-debugging），通过再进下一步
4. 遇到计划外需求：先记录为"待定项"，完成当前计划后再处理

## 完成标准
- 所有步骤执行完毕且各自验证通过
- 最终跑一次整体验证（build/test/冒烟）
- 输出：每步的改动 + 验证证据

## 与计划冲突
- 计划与实际冲突时，先改计划（说明原因）再继续，不要默默偏离
