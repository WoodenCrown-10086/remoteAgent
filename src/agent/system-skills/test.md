# Test（测试驱动修复）

## 流程
1. 找到并运行项目测试命令（npm test / pnpm test / pytest 等），拿到失败列表
2. 对每个失败：
   - 读失败输出定位：断言失败 vs 运行时错误 vs 编译错误
   - 缩小范围：单测可单独跑该用例复现
   - 修复根因（不是掩盖断言）
3. 修复后复跑该用例 → 通过后再跑全量
4. 全部通过后检查是否新增了回归

## 规则
- 不要为了"变绿"删测试或改断言绕过
- 失败涉及多文件时按依赖顺序修
- 最多尝试 2 次同类修复仍失败 → 停下换思路（可能是测试本身写错，需先确认测试期望是否合理）

## 输出
- 失败原因 → 修复方式 → 验证结果，逐条说明
