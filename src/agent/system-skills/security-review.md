# Security Review（安全审查）

## 必查项
1. **注入**：SQL 拼接、shell 命令拼接、HTML/模板注入（XSS）、SSRF
2. **认证/授权**：身份校验、越权（IDOR）、敏感接口缺少鉴权、默认口令
3. **密钥**：硬编码、日志打印、前端泄露、环境变量遗漏
4. **反序列化**：不可信输入反序列化（JSON/eval/pickle 等）
5. **路径遍历**：用户输入拼接文件路径（../、绝对路径）
6. **加密**：敏感数据明文存储/传输、弱哈希、弱随机数

## 输出
- 每条：`文件:行号 - 严重度(严重/高危/中危/低危) - 漏洞描述 - 利用场景 - 修复建议`
- 修复优先级：严重/高危必须修，中危列计划，低危备注

## 原则
- 外部输入默认不可信，所有边界都验证
- 最小权限：只开放必要的能力
